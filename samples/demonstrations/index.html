Recipe 05 · Physics data

Seeded point set from Physics

Read the recipe →

Physics owns the deterministic point generation and exports a versioned run record. GUI.SVG consumes that record and verifies each rendered marker against the original coordinates; it does not regenerate the points. The generated SVG is attached as a CI artifact so the source-data hand-off can be inspected.

Recipe 06 · Physics mathematics

Parameterized Mandelbrot field

Explore the recipe →

Compare a default overview with a configurable detail window. Physics generates each actual sample record; GUI.SVG renders and verifies every cell without recomputing the fractal. CI uploads both records and both SVGs for inspection. The current explorer is reproducible command-line configuration, not yet an interactive browser panel.
