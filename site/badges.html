Badges with a job to do.

A badge should communicate a meaningful property at a glance, point to its evidence, and make uncertainty visible. This gallery documents the visual vocabulary; it is not a claim that live status wiring is deployed.

Important: these Autonomous Design SVGs are presentation assets. Foundry remains authoritative for lifecycle; CiAi remains authoritative for dependency evidence. Until those contracts and delivery are connected, do not interpret these static examples as current repository status.

Autonomous Design lifecycle

These states describe the autonomous-work lifecycle, not CI health. A failed build can occur while autonomous repair is still WORKING. Unknown or stale telemetry must never appear as OFF.

OFF

Explicitly disabled by the authoritative lifecycle owner.

assets/autonomous-design/off.svg
WORKING

Autonomous work is actively progressing, including diagnosis, CI, repair, and revalidation.

assets/autonomous-design/working.svg
AWAITING HUMAN REVIEW

A healthy handoff is waiting at a human decision or approval boundary.

assets/autonomous-design/review.svg
STATUS UNAVAILABLE

Missing, stale, malformed, or contradictory telemetry prevents a trustworthy lifecycle claim.

Required dependency readiness

When should we create another badge?

Only when it answers a recurring, useful question that cannot be answered more clearly by an existing badge or link. Every proposed badge needs a defined audience, authoritative source, verifiable evidence, freshness behavior, and a useful destination. Avoid badges that merely decorate a README or duplicate a workflow's green check.
