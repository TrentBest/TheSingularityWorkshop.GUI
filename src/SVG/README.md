# ✳️ 00 The Singularity Workshop — GUI.SVG

**Hand-authored diagrams drift away from the code that is meant to explain them.** GUI.SVG turns the Workshop's platform-neutral GUI model into standalone, inspectable SVG output when an actual semantic GUI tree is the source.

## 🟦 01 What

GUI.SVG is the SVG interoperability adapter for `GuiNode` snapshots. It maps GUI semantics—such as grouped content, labels, accessibility metadata, and GUI-authored visual elements—to an SVG document. It is not the general-purpose owner of Visualize scenes, geometry, materials, or draw-command output.

For general visual scenes and Visualizer frames, use the Visualize-owned SVG artifact backend. See the [Visualize SVG ownership issue](https://github.com/TrentBest/TheSingularityWorkshop.Visualize/issues/34) and [paired GUI adapter issue](https://github.com/TrentBest/TheSingularityWorkshop.GUI/issues/61).

## 🟣 02 Why

Keep semantic interaction separate from visual manifestation. GUI Core owns the neutral interface tree; GUI.SVG owns mapping from that tree into SVG-specific elements and attributes. Visualize owns general scene-to-image/artifact output and must not need GUI merely to serialize a visual scene.

## 🔺 03 How

Build a semantic GUI tree with `GuiBuilder`, then call `new SvgGuiRenderer().Render(scene)`. Use this when the input is a GUI tree and SVG is the chosen GUI manifestation. For Visualizer frames, geometry, materials, and draw commands, use Visualize's independent `SvgVisualizerBackend`; that route does not depend on GUI.Core or GUI.SVG. See the adapter guide for the supported GUI-node vocabulary, coordinate-system rules, animation boundaries, and tests.

## 🟢 04 See it in a minute

![GUI.SVG generated feature gallery](../../docs/assets/svg-adapter-gallery.svg)

This gallery is generated by the C# sample during CI. Its SVG includes gradients, clipping, patterns, markers, symbol reuse, navigable links, filter graphs, and motion/attribute animation. Animation is presentation data interpreted by a compatible SVG viewer; it does not run FSM_API or turn this adapter into a GPU renderer.
