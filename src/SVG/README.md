# ✳️ 00 The Singularity Workshop — GUI.SVG

**Hand-authored diagrams drift away from the code that is meant to explain them.** GUI.SVG turns the Workshop's platform-neutral GUI model into standalone, inspectable SVG output so documentation visuals can be generated from the same scene data they describe.

## 🟦 01 What

GUI.SVG is the SVG manifestation adapter for `GuiNode` snapshots. It emits vector geometry, text, reusable definitions, links, accessibility metadata, filters, and declarative SVG animation.

## 🟣 02 Why

Keep scene meaning separate from the display format. The GUI Core model remains platform-neutral; this package owns SVG element names, SVG attributes, coordinate conventions, and XML serialization.

## 🔺 03 How

Build a scene with `GuiBuilder`, then call `new SvgGuiRenderer().Render(scene)`. See the adapter guide for the complete node vocabulary, coordinate-system rules, animation boundaries, and tests.

## 🟢 04 See it in a minute

![GUI.SVG generated feature gallery](../../docs/assets/svg-adapter-gallery.svg)

This gallery is generated by the C# sample during CI. Its SVG includes gradients, clipping, patterns, markers, symbol reuse, navigable links, filter graphs, and motion/attribute animation. Animation is presentation data interpreted by an SVG viewer; it does not run FSM_API or turn this adapter into a GPU renderer.
