## Audit notes

- The inventory records source-declared names and namespaces, not inferred architectural relationships. Relationships must be checked against source and tests before drawing each UML diagram.
- The scan exposed namespace variation in the Blazor area: `BlazorGuiRenderer` is declared in `TheSingularityWorkshop.Workshop.Gui`, while the other listed Blazor types use `TheSingularityWorkshop.Gui`. This is recorded as source fact, not silently normalized; review whether that split is intentional.
- The final inventory must be regenerated or compared with a C# syntax model in CI. A handwritten inventory alone cannot prove drift-free coverage.
- A page or diagram is not complete merely because a file exists: the SVG must describe verified relationships, include `title` and `desc`, and have a textual fallback on the page.
