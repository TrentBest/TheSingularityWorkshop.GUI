# SVG Visual Concepts

These files preserve exploratory, hand-authored SVG artwork from older GUI branches. They are concept art, not generated evidence.

- [GUI semantic boundary](../assets/concepts/gui-semantic-boundary.svg) illustrates the intended separation between semantic GUI data and platform manifestations. Its animation is authored directly in SVG/CSS.
- [Living energy vortex](../assets/concepts/living-energy-vortex.svg) is an animated visual experiment around a digital-eye/energy-field motif.

**Evidence boundary:** neither file is generated by SvgGuiRenderer, nor does either prove that the current framework produces animated or interactive SVG scenes. Treat them as design concepts only. Framework behavior must be demonstrated by generated output and automated or hosted tests. Check accessibility, reduced-motion behavior, browser rendering, and local references before using them as release evidence.

See [Living Documentation](../LIVING_DOCUMENTATION.md) and the [GUI Gallery](../GALLERY.md) for the evidence labels used by this repository.
